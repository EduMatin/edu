## 本地启动

双击 `启动Matin.bat`。它使用本机 Python 3 启动只监听本机的静态服务，并打开教师端：

- 教师端：<http://127.0.0.1:8765/teacher.html>
- 学生端：<http://127.0.0.1:8765/index.html>

重复启动会复用相同服务。关闭浏览器不等于关闭服务；可双击 `停止Matin.bat` 停止本项目启动的服务。

当前电脑使用 `%LOCALAPPDATA%\Programs\Python\Python313\python.exe`，无需第三方 Python 包。换电脑后安装 Python 3，或在本目录创建 `.venv`。也可从本目录手动运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

手动启动的终端用 Ctrl+C 停止。不要直接双击学生端 HTML，读取 `catalog.json` 需要 HTTP 服务。保持相同浏览器、主机名和端口，才能继续使用同一份浏览器本地草稿。

## 教师与学生数据

教师端可编辑示例剧本、保存草稿、导入和导出剧本 JSON，并通过“教师预览”测试规则回复。草稿在当前浏览器 localStorage 中，保存草稿不会自动改写本地 `catalog.json`。

离线向学生提供课程时，在教师端导出课程库，先备份本项目 `catalog.json`，再将导出的完整课程库文件替换它；学生刷新页面即可读取。不要将单个剧本 JSON 直接粘入课程库文件中。

本地学生端读取 `catalog.json`，选课后可使用离线规则回复和阶段切换；线上学生端读取 Supabase 云端课程。课程来源与 AI 服务配置相互独立，读取云端课程不代表已接通真实 AI。真正的大模型生成、AI 评分和在线对话需要另行配置服务与凭据，本次未验证。

教师草稿始终保存在当前浏览器对应网站地址的 localStorage 中。仅保存草稿不会发布云端课程；使用教师端云端发布功能需要相应发布口令和权限。切换电脑、浏览器或从本地网址切换到线上网址时，需要导出、导入草稿；云端已有课程不能据此视为草稿已自动同步。
